Entry for the [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) bounty on make.fun.

## What it does

`main.py` writes a single funny line (200 characters or fewer) to `/output/entry.txt`. An AI judge compares entries two at a time and the funniest lines share the $2 reward pool.

## Run

```sh
python3 main.py
```

The entry text is written to `/output/entry.txt`.
